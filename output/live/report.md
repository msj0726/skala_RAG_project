# SUMMARY

시장에서는 MLA 계열의 서비스 운영과 CXL 계열의 제품 기반이 서로 다른 형태로 확인된다. 도메인에서는 MLA의 KV 감소를 정량화할 수 있지만, PNM의 최대 문맥 수치는 동일 조건 증가 배수로 환산할 수 없다. 두 기술 모두 코딩·업무 에이전트의 TTFT·TPOT·비용을 함께 충족하는 근거가 부족해 응답성과 비용 효율은 판정을 유보한다. 이는 기술 우열이 아니라 공개 근거의 범위 차이를 보여준다. [S1] [S2] [S3] [S4] [S5] [S6] [S7] [S8] [S9]

평가 기준일: 2026-09-23 | 대상: AI 코딩·업무 에이전트 | 시장·도메인 2개 관점

실행: OpenAI 실시간 조사 + WebSearch + 원문 벡터 검색; 최종 판정은 검토 원장과 대조

## 1. 분석 배경

자기회귀 생성은 이전 토큰의 Key와 Value를 보관해 반복 계산을 줄인다. 코드·대화·도구 출력이 누적되면 KV 메모리와 읽기 부담이 커진다. 두 접근은 이 병목을 각각 표현 압축과 외부 메모리/근접 연산으로 다룬다. [S1] [S2]

기술 선택은 사람이 완료했다. 실행마다 같은 조합을 비교해 검색 전략과 문서 풀을 고정한다. 선정 기준은 접근의 대표성, 변경 전제의 대조성, 시장·도메인 두 관점의 자료 확보 가능성이다. 선정 능력 자체는 평가하지 않는다.

## 2.1 SW: DeepSeek-V2 MLA

저차원 잠재 벡터로 KV를 표현하는 아키텍처 개선 접근이다. 본 분석은 2024년 6월 개정본을 사용한다. 기존 GPU 인프라에서 실행할 수 있지만 모델 구조와 대응 커널이 전제된다. 사후 양자화처럼 임의 모델에 그대로 적용하는 방식이 아니다. [S1] [S3]

## 2.2 HW: 1M-Token LLM Inference의 CXL-PNM

CXL 메모리의 PNM 가속기로 KV 관련 선택·연산을 옮긴다. PNM-KV와 GPU 병행 방식 PnG-KV를 다루는 2025년 10월 31일 원문을 선정했다. PIM/CXL은 과제상의 포괄 명칭이고, 원문의 구체 방식은 Processing-Near-Memory다. [S2]

## 평가 단위

도메인의 정량치는 선정 논문 단위로 평가한다. 시장은 MLA 계열과 PIM/PNM·CXL 메모리 계열까지 확장하되 원 기술과 구분한다. 일반 CXL 제품과 규격은 해당 PNM 구현의 상용 운영 증거가 아니다. [S2] [S6] [S7]

# 3. 평가 방법

## M1 성장성: 2026-09-23 이후 3년

세부 항목은 수요 동인·채택 확대·공급/생태계 투자다. 각 0점=긍정 근거 미확인, 1점=단일 사례 또는 간접 동인, 2점=독립된 복수 사례 또는 시간상 확장 근거. 합계 0~1 낮음, 2~3 보통, 4~5 높음, 6 매우 높음으로 코드가 계산한다. 항목 구체화는 구현 시 보완한 운영 규칙이며 성장률 예측 모델은 아니다.

## M2 채택 / M3 생태계

M2는 채택 주체와 근거가 있는 사례의 최고 단계를 계산한다: L4 상용 운영, L3 제품화, L2 시범·PoC, L1 연구, L0 미확인. 선정 기술과 계열의 최고 단계를 각각 산출한다.

M3는 프레임워크·벤더 제품·표준화·제3자 연구/도구의 네 항목을 원문 청크로 교차 확인한다. Y 3~4개 L3, 1~2개 L2, 0개이지만 원저자 구현이 있으면 L1, 둘 다 없으면 L0. 같은 구현을 중복 집계하지 않는다. N은 수집 자료 내 미확인이다.

## D1 장기 세션 수용성

KV 감소율 r은 1/(1-r)의 동일 예산 환산치로 변환하거나, 같은 조건의 최대 문맥·세션 증가 배수를 사용한다. 4배 이상 L3, 2배 이상~4배 미만 L2, 1배 초과~2배 미만 L1, 1배 이하·근거 없음 L0. 2배·4배 경계는 상위 구간으로 통일했다. 예산 환산치와 실제 세션 길이는 구별한다.

## D2 응답성과 비용 효율

동일 조건 TTFT·TPOT 중 큰 지연 증가율로 판정한다. 비용 절감이 있고 SLA를 만족하면서 지연 증가 없음 L3, 10% 이내 L2, 10% 초과 L1. 비용 절감 없음 또는 SLA 미충족은 L0. 필요한 지표가 없으면 판정 유보로 남긴다. SLA 수치는 도입 환경에 따라 별도 정의해야 한다.

모든 점수는 구조화된 근거를 검증한 뒤 코드로 계산한다. LLM은 근거 해석과 설명을 담당한다. 자료가 부족하면 재검색을 최대 1회 수행하며 미확인을 숫자로 보충하지 않는다.

수요 동인 1/2: 장문맥 KV 부담을 줄이는 메커니즘은 확인되지만 향후 3년의 기술별 수요 시계열·시장 규모는 확보하지 못했다. [S1]

채택 확대 2/2: V2 이후 V3가 MLA를 유지하고, V3 기반 R1을 AWS가 일반 제공하며 실제 고객 배포를 보고했다. 계열 확산 근거이며 V2 자체의 고객 수는 아니다. [S5] [S8] [S9]

공급·생태계 투자 1/2: vLLM MLA 백엔드와 FlashMLA 구현은 공급 기반의 존재를 뒷받침한다. 투자 규모의 연속 증가를 증명하지는 않는다. [S3] [S4]

## M2 채택: 선정 L1 / 계열 L4

DeepSeek-AI · 선정 · L1: V2 논문과 모델 공개를 확인했다. 본 자료 풀만으로 V2의 현재 상용 운영을 확정하지 않는다. [S1]

AWS / Amazon Bedrock 고객 · 계열 · L4: AWS는 R1의 정식 서비스와 수천 고객의 배포를 보고했다. R1→V3→MLA 연결은 모델 원문으로 확인했다. 벤더 자기보고이며 선정 V2의 운영 증거는 아니다. [S5] [S8] [S9]

프레임워크 Y: vLLM 문서가 MLA 전용 prefill/decode 백엔드를 열거한다. [S3]

벤더 제품 Y: AWS의 R1 서비스 제공과 원 모델 계보로 MLA 계열 제품을 확인한다. [S5] [S8] [S9]

표준화 N: 조사 자료에서 MLA 자체의 산업 표준은 확인하지 못했다.

제3자 연구·도구 N: 중복 집계를 피하고 vLLM은 프레임워크로만 계수했다. FlashMLA는 원 개발자의 도구로, 제3자 항목에 포함하지 않았다. [S3] [S4]

원저자 구현: 확인 [S1] [S4]

M1은 2026-09-23부터 3년을 바라보는 정성적 전망이다. 4점은 성장률 예측이나 시장 점유율을 뜻하지 않는다. M2의 최고 단계는 채택의 보편성을 뜻하지 않는다.

# 4. 시장성 평가 / CXL-PNM (PNM-KV / PnG-KV)

## M1 성장성: 보통 (3/6)

수요 동인 1/2: 장문맥과 외부 KV 메모리의 전송 병목은 논문이 다룬다. 실제 고객 수요가 연속 증가했다는 자료는 부족하다. [S2]

채택 확대 1/2: CXL 메모리 계열 제품 페이지는 확인되지만 선정 PNM-KV/PnG-KV의 상용 고객 사례는 확인되지 않았다. [S6] [S2]

공급·생태계 투자 1/2: CXL 규격과 메모리 제품이 기반을 제공한다. 선정 PNM 구조에 대한 지속 투자 규모와 대량 출하는 별도 검증이 필요하다. [S7] [S6]

## M2 채택: 선정 L1 / 계열 L3

Kim et al. 연구팀 · 선정 · L1: 논문은 합성 타이밍·전력 모델로 보정한 사이클 수준 시뮬레이터를 평가에 사용했다. 이 자료만으로 현장 PoC 또는 상용 운영으로 올리지 않는다. [S2]

Samsung Electronics · 계열 · L3: CMM-D 공식 제품 자료를 확인했다. CXL 메모리 제품이며 해당 논문의 PNM 가속 기능과 동일한 제품이라는 뜻은 아니다. [S6]

## M3 생태계: L2 (2/4)

프레임워크 N: 논문 자체 런타임은 외부 프레임워크 지원과 구별했다. 선정 구조의 범용 프레임워크 통합은 미확인이다. [S2]

벤더 제품 Y: CMM-D가 CXL 메모리 계열의 제품 근거다. PNM-KV 제품의 증거는 아니다. [S6]

표준화 Y: CXL Consortium의 규격 아카이브가 존재한다. PNM 토큰 선택 알고리즘 자체의 표준은 아니다. [S7]

제3자 연구·도구 N: 선정 논문을 자기 자신의 제3자 연구로 집계하지 않았다. 별도 원문을 확보하지 못한 항목은 N으로 남겼다.

원저자 구현: 확인 [S2]

계열 범위를 넓히면 제품·표준의 근거가 늘지만 선정 논문의 상용성은 올라가지 않는다. N은 조사 범위 내 미확인이며 부존재의 증명이 아니다.

# 5. 도메인 평가 / AI 코딩·업무 에이전트

## DeepSeek-V2 MLA

D1: L3 / 14.925배 예산·용량 비교. DeepSeek-V2 대 DeepSeek 67B의 KV cache 비교. 1/(1-0.933)=14.925배의 동일 KV 예산 환산치이며 실측 세션 길이 배수가 아니다. [S1]

D2: 판정 유보. 논문의 최대 처리량 향상을 TTFT·TPOT로 바꾸지 않는다. KV 감소율은 총 운영비 감소율이 아니다. 동일 코딩 에이전트 조건의 지연·비용·SLA 자료가 없다. [S1]

도메인 해석: 장기 세션당 KV 예산 감소에 연결되는 구조다. 실제 보존 가능한 코드·대화 길이는 모델 문맥 한도, 가중치 메모리, 동시 사용자, 도구 출력량에 함께 제약된다.

적용 한계: MLA 지원 모델과 커널이 필요하다. 일반 모델에 설정 하나로 적용하는 압축 기법이 아니다. 보고된 비교는 모델 구조가 다른 세대 간 비교이며 MLA만의 통제 실험으로 일반화하지 않는다.

## CXL-PNM (PNM-KV / PnG-KV)

D1: L0 / 비교 근거 없음. 최대 1M 문맥 실험은 확인되지만 128K→1M을 동일 하드웨어의 최대 문맥 증가 배수로 간주할 수 없다. GPU·PNM 수가 함께 바뀌며 기준 시스템도 CXL 확장 메모리를 사용한다. [S2]

D2: 판정 유보. 평가는 주로 decode 단계와 처리량/달러를 다룬다. 대화형 TTFT를 포함한 동일 SLA 비교가 없으므로 최대 비용 효율 수치만으로 D2를 확정하지 않는다. [S2]

도메인 해석: 여러 세션의 KV를 외부 메모리에 수용하고 선택 연산을 메모리 근처에서 처리하는 방향이다. 다수 에이전트의 동시 운용 가능성은 분석적 해석이며 코딩 에이전트 실측은 아니다.

적용 한계: 추가 CXL-PNM 하드웨어·드라이버·서빙 경로가 필요하다. 논문은 시뮬레이션 기반 성능 평가이며 요약 작업의 결과를 실제 도구 호출 세션에 직접 전이할 수 없다.

장문맥의 수용과 유효한 기억은 같지 않다. 코드 변경 추적, 검색 정확도, 도구 호출 성공률과 같은 업무 품질은 이 KV 비교만으로 검증되지 않는다.

# 6. 시사점과 한계

## 관점 사이의 차이

시장 채택 단계가 높더라도 특정 코딩 에이전트의 응답 SLA 충족이 보장되지는 않는다. MLA 계열 서비스 존재와 D2 판정 유보는 모순되지 않는다.

외부 메모리 수용량의 확대와 토큰당 KV 압축은 서로 다른 변경 지점을 가진다. 동일 환경 실측 없이 양자의 수치를 직접 순위화하거나 합산하지 않는다.

계열의 제품·규격 지원은 연구 기술의 도입 기반이 될 수 있지만, PNM 논문 자체의 상용 운영 증거와 구분해야 한다.

## 공개 정보와 평가 절차의 한계

공개 자료와 벤더 자기보고를 사용했으며 독립적 실측은 수행하지 않았다. 상용 사용량·투자액·향후 3년 성장률은 확인하지 못했다.

시장 조사는 MLA 및 PIM/PNM·CXL 기술 계열로 넓혔다. 도메인 수치는 선정 논문 단위를 유지했다. PIM은 포괄 명칭이며 선정 논문의 구체 방식은 PNM이다.

M1 세부 3항목과 D2 판정 유보 정책은 미정의 부분을 보완한 운영 규칙이다. M3에서는 동일 근거를 여러 범주에 중복 집계하지 않았다.

검색 원문에 근거 ID·페이지·범위를 연결하고, 긍정 주장과 제약을 함께 기록했다. 미확인 자료를 실패나 부존재로 단정하지 않으며 합산 승자를 만들지 않았다.

## 실행 추적

원문 9개, PDF 실페이지와 웹 환산페이지 합계 152페이지. 웹은 3,000자당 1페이지로 별도 환산했다. 임베딩: intfloat/multilingual-e5-small. 검색 청크 ID와 원문 해시, 검색어, 판정 입력은 evaluation.json과 실행 trace에 기록했다.

시장 평가는 WebSearch와 M3 원문 교차 확인, 도메인 평가는 VectorRetriever와 WebSearch를 사용한다. 실시간 모드의 모델 제안은 evaluation.json에 남긴다. 검토 원장과 불일치한 수치·해석은 보고서에 반영하지 않고, 종합 의견도 검토된 기록으로 구성한다. 재현 모드는 WebSearch·OpenAI 호출을 생략한다.
